# KDJ 副图坐标轴与交叉标签统一实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将详情页 KDJ 副图纵轴移到左侧，并恢复与 MACD 一致的金叉、死叉顶部文字。

**Architecture:** 保持现有 `buildKlineOption` 图表结构和指标数据不变，只调整 KDJ 对应的 ECharts 纵轴位置及交叉标记标签开关。20/80 边界线和三区背景继续通过父级标签配置隐藏文字，交叉线则使用自身标签配置覆盖并显示。

**Tech Stack:** React、TypeScript、Apache ECharts、Vitest

## Global Constraints

- KDJ 纵轴与 MACD 一样显示在左侧。
- KDJ 金叉、死叉顶部显示“金叉/死叉 + 日期”。
- 20/80 边界线及超卖区、普通区、超买区不显示文字。
- 不修改 KDJ 计算、接口数据、筛选或静默刷新逻辑。
