# MACD 与 KDJ 指标图层合并修复实施计划

> **供自动化执行者使用：** 必须使用 `executing-plans` 按任务执行；每个任务遵循测试先行、验证、提交的顺序。

**目标：** 将完整 MACD 背离能力合入当前 KDJ 主线，恢复普通高低点、背离及 MACD 交叉标记，并把 KDJ 金叉死叉统一为 MACD 的竖向虚线表现后重新上线。

**架构：** 以当前 `main` 为基线，在隔离工作树中合并 `codex/macd-divergence`，冲突按“字段并集、服务能力并集、图层并集”解决。后端 MACD 响应恢复 `divergences`，同时保留 KDJ 表、接口和刷新路径；前端图表保留四个联动区域，并让 MACD 与 KDJ 交叉复用同一个竖线构造器。

**技术栈：** Python 3.12、FastAPI、DuckDB、pytest、React 19、TypeScript、ECharts、Vitest、Playwright、Docker Compose、Nginx。

## 全局约束

- 所有说明、测试名称和新增文档使用中文。
- MACD、背离和 KDJ 的计算公式及判定口径保持不变。
- MACD 背离继续只用于日 K；其他周期只展示交叉。
- KDJ 继续支持今日、1/5/15/30/60 分钟、日 K、周 K、月 K。
- KDJ 的 20/80 横线与三区背景必须保留。
- KDJ 金叉死叉与 MACD 交叉使用相同的竖向虚线、颜色、透明度和标签布局。
- 不新增第三方依赖，不破坏线上 DuckDB 已有数据。
- 每个实现任务结束后先跑聚焦测试，再提交。
