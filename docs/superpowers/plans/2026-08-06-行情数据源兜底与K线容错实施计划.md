# 行情数据源兜底与 K 线容错 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让日 K 和分钟 K 在东方财富临时断连时自动切换到可用公开源，并且接口在无缓存时返回可解释的空结果，不再 500。

**Architecture:** 数据源兜底放在 `AkshareSource` 内部，服务层继续只依赖 `MarketDataSource` 协议。`BarService` 负责记录失败审计和返回缓存或空列表，前端继续通过现有元数据展示“数据不完整/可能过期”。

**Tech Stack:** Python 3.13、FastAPI、AKShare、SQLite 仓储、pytest。

## Global Constraints

- 描述性内容使用中文。
- 日 K 默认仍保存前复权 `qfq` 的 60 个交易日，并永久保留已落库历史。
- 分钟 K 详情页按需拉取并落库，不做全市场分钟级全量采集。
- 周 K 和月 K 暂时继续走现有历史 K 通道。
- 免费公开源失败时不让页面 500，审计中记录失败状态，页面返回已有缓存或空数组。
