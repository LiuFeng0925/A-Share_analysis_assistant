# KDJ 指标筛选与多周期详情 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 MACD 链路旁新增标准 `9,3,3` KDJ，实现全周期详情副图和信号卡片、日 K 列表筛选与结果列，以及页面可见时不闪烁的静默刷新。

**Architecture:** KDJ 使用独立领域模型、纯计算模块和 DuckDB 最新值/序列表，`IndicatorService` 复用现有周期取数与过期判断编排。详情页并行获取 K 线、MACD、KDJ，ECharts 使用第四个联动网格；列表查询只关联 `period='1d'` 的 KDJ 最新摘要。

**Tech Stack:** Python 3.12、FastAPI、DuckDB、pytest、React 19、TypeScript 7、ECharts 6、Vitest、Testing Library、Playwright。

## Global Constraints

- KDJ 参数固定为 `9,3,3`；前置 K、D 均为 `50`，九周期最高价等于最低价时 RSV 为 `50`。
- 金叉为 `K_(t-1) <= D_(t-1) 且 K_t > D_t`，死叉为反向条件；J 不参与交叉判定且不截断。
- 信号区域按信号柱 K、D 同时 `<=20`、同时 `>=80` 或其他，分别归为低位、高位、中位。
- 详情支持 `1m/5m/15m/30m/60m/1d/1w/1mo`；“今日”仍使用 `1m + today`；列表筛选始终使用日 K。
- KDJ 图必须显示 20、80 虚线、三个区域底色、K/D/J 曲线和交叉标记，并与 K 线、成交量、MACD 共用缩放和十字轴。
- 页面可见且开市时每 60 秒静默更新；隐藏页暂停，恢复可见立即更新；单项失败保留旧数据，避免请求重叠和加载闪烁。
- 不增加全市场分钟 KDJ、参数自定义、回测、推送、KDJ 背离或快照伪造分钟 K 线。

```python
class KdjSignal(StrEnum):
    NONE = "none"
    GOLDEN_CROSS = "golden_cross"
    DEATH_CROSS = "death_cross"

class KdjZone(StrEnum):
    OVERSOLD = "oversold"
    NEUTRAL = "neutral"
    OVERBOUGHT = "overbought"
    UNKNOWN = "unknown"

class KdjSignalZone(StrEnum):
    LOW = "low"
    MIDDLE = "middle"
    HIGH = "high"
    UNKNOWN = "unknown"

class KdjQuality(StrEnum):
    OK = "ok"
    PARTIAL = "partial"
    INSUFFICIENT = "insufficient"
    ERROR = "error"
```

`KdjPoint` 保存 `market/code/period/bar_time/k_value/d_value/j_value/signal_type/signal_zone/current_zone/is_intraday/quality`；`KdjSummary` 额外保存 `calculated_at/market_time/signal_time/recent_signal_days/recent_signal_label/status`；`KdjCalculation` 保存摘要与不可变点序列。

```python
def _classify_zone(k_value: float, d_value: float) -> KdjZone:
    if k_value <= 20 and d_value <= 20:
        return KdjZone.OVERSOLD
    if k_value >= 80 and d_value >= 80:
        return KdjZone.OVERBOUGHT
    return KdjZone.NEUTRAL

def _classify_signal_zone(k_value: float, d_value: float) -> KdjSignalZone:
    return {KdjZone.OVERSOLD: KdjSignalZone.LOW,
            KdjZone.OVERBOUGHT: KdjSignalZone.HIGH}.get(
                _classify_zone(k_value, d_value), KdjSignalZone.MIDDLE)
```

计算时从第 9 根柱开始滚动最高/最低，先更新 K 再更新 D；只比较相邻两个有效 KDJ 点。少于 9 根返回 `quality=insufficient` 的空序列；动态柱沿用 MACD 的日 K 合并和 `is_intraday/partial` 规则。

- [ ] **Step 3: 建表并实现单锁事务写入**

`indicator_kdj_latest` 主键为 `(market, code, period)`，保存摘要所有字段，其中 `signal_time TIMESTAMPTZ`；`indicator_kdj_series` 主键为 `(market, code, period, bar_time)`，保存每点字段。

```python
def upsert_kdj(self, calculation: KdjCalculation) -> None:
    with self._lock:
        self._connection.execute("BEGIN TRANSACTION")
        try:
            self._replace_kdj_latest(calculation.summary)
            self._connection.execute(
                "DELETE FROM indicator_kdj_series WHERE market=? AND code=? AND period=?",
                [calculation.summary.market.value, calculation.summary.code,
                 calculation.summary.period],
            )
            self._insert_kdj_points(calculation.points)
            self._connection.execute("COMMIT")
        except Exception:
            self._connection.execute("ROLLBACK")
            raise
```

读取时显式转换所有枚举；没有最新摘要时返回 `None`，有不足摘要时返回空 `points`。
