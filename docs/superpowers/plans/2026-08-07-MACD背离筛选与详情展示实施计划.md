# MACD 背离筛选与详情展示实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 在不改变现有 MACD 金叉、死叉能力的前提下，为日 K 增加四种可多选背离状态、对应交叉筛选、详情摘要和图表节点解释。

**架构：** 新增纯计算模块，从日 K 与现有 MACD 点序列生成背离事件；事件按“方向 + 状态”存入 DuckDB，并随现有 MACD 刷新链路重算。列表接口查询预计算事件，详情接口返回有效事件供右侧卡片和 ECharts 标记使用；其他 K 线周期继续只返回普通 MACD。

**技术栈：** Python 3.13、FastAPI、Pydantic、DuckDB、pytest、React 19、TypeScript、Vitest、Testing Library、ECharts 6、CSS。

## 全局约束

- 所有描述性文案、测试名称和新增文档使用中文。
- 第一版只计算日 K 背离，背离只比较 DIFF，不比较 DEA 或 MACD 柱。
- 历史锚点使用左右各 3 根 K 线确认；当前候选新高、新低不等待右侧 K 线。
- 底背离要求当前最低价低于最近两个确认低点且当前 DIFF 高于两个锚点 DIFF；顶背离完全反向。
- 用户可见背离选项固定为 `bottom_forming`、`bottom_confirmed`、`top_forming`、`top_confirmed`，支持多选。
- 普通金叉、死叉独立计算、独立保存、独立展示；背离失效不能删除普通交叉事件。
- 对应交叉只统计当前候选节点同一根或之后的金叉、死叉；候选节点移动后重新判断。
- 看涨使用红色，看跌使用绿色；形成中使用浅色，已确认使用实色。
- 不新增第三方依赖，不改变现有行情源和部署方式。
- 每项任务遵循“失败测试 → 最小实现 → 通过测试 → 提交”。

- [ ] **步骤 4：实现纯计算状态机**

新增函数签名和固定常量：

```python
PIVOT_SIDE_BARS = 3


def calculate_macd_divergences(
    bars: Sequence[Bar],
    points: Sequence[MacdPoint],
    trading_days: Sequence[date],
) -> tuple[MacdDivergenceEvent, ...]:
    if len(bars) != len(points):
        raise ValueError("K 线与 MACD 点数量必须一致")
    if any(bar.bar_time != point.bar_time for bar, point in zip(bars, points, strict=True)):
        raise ValueError("K 线与 MACD 点时间必须一一对应")
    if not bars or bars[0].period != "1d":
        return ()
    lows = _confirmed_pivots(bars, points, MacdDivergenceDirection.BOTTOM)
    highs = _confirmed_pivots(bars, points, MacdDivergenceDirection.TOP)
    events = [
        *_scan_direction(bars, points, trading_days, lows, MacdDivergenceDirection.BOTTOM),
        *_scan_direction(bars, points, trading_days, highs, MacdDivergenceDirection.TOP),
    ]
    return tuple(sorted(events, key=lambda event: (event.detected_at, event.direction.value)))
```

`_confirmed_pivots` 只有在 `pivot_index + 3 <= current_index` 时才把锚点提供给扫描器。`_scan_direction` 实现：无候选→形成中；更极端且仍背离→移动节点并清空旧交叉；更极端且不再背离→失效；连续三根未突破→已确认；当前节点同根或之后发生对应交叉→记录交叉。`recent_days` 使用交易日序号差，形成中按 `pivot_time`、已确认按 `confirmed_at`。

定义：

```python
_MACD_DIVERGENCE_KEYS = {
    "bottom_forming": ("bottom", "forming"),
    "bottom_confirmed": ("bottom", "confirmed"),
    "top_forming": ("top", "forming"),
    "top_confirmed": ("top", "confirmed"),
```

存在背离条件时使用单个相关子查询，不能用普通 JOIN 放大股票行：

```sql
EXISTS (
  SELECT 1
  FROM indicator_macd_divergence d
  WHERE d.market = s.market
    AND d.code = s.code
    AND d.period = '1d'
    AND d.is_valid = TRUE
    AND ((d.direction = ? AND d.status = ?) OR (d.direction = ? AND d.status = ?))
    AND d.corresponding_signal <> 'none'
    AND d.recent_days <= ?
)
```

只为实际选中的类型、交叉、时间生成片段。未选类型但选择交叉或时间时，对任意有效背离生效。股票摘要使用相关子查询 `string_agg(direction || '_' || status, ',')`，解析成去重元组。

```typescript
function divergenceMarkPoint(event: MacdDivergence, value: number) {
  const bullish = event.direction === "bottom";

  };
}
```
