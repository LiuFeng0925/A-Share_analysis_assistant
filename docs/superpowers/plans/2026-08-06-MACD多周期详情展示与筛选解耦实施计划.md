# MACD 多周期详情展示与筛选解耦 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让个股详情页支持当前 K 线周期对应的 MACD，同时保持列表页 MACD 筛选只查询已保存的日K结果。

**Architecture:** 后端把 MACD 计算从日K专用函数改成周期参数化函数；指标接口按周期读取或补算单只股票的 MACD；前端详情页把当前 K 线周期传给 MACD 接口，并只在周期匹配时把 MACD 传给图表。列表页继续通过 `indicator_macd_latest` 的 `period = '1d'` 结果筛选，避免全市场分钟级计算。

**Tech Stack:** Python 3.12、FastAPI、DuckDB、pytest、React 19、TypeScript、Vitest、ECharts。

## Global Constraints

- 分钟级 MACD 只在个股详情页查看。
- 全市场筛选暂不做分钟级 MACD。
- 全市场筛选默认继续以日K MACD 为主。
- 指标筛选不能在用户点击筛选时触发全市场实时计算。
- “今日”页使用 `1m` K 线，因此对应展示 `1m` MACD。
- MACD 公式不因周期变化而变化：`DIFF = EMA(12) - EMA(26)`，`DEA = EMA(DIFF, 9)`，`MACD 柱 = 2 × (DIFF - DEA)`。
- 数据不足时不生成金叉/死叉，质量标记为 `insufficient`。
- 详情页 MACD 加载失败不能影响 K 线展示。
- 所有新增和修改的描述性文案使用中文。
