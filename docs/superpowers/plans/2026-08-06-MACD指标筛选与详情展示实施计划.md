# MACD 指标筛选与详情展示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 A 股行情系统增加日线 MACD 计算、最近金叉/死叉列表展示、MACD 多维筛选、详情页 MACD 指标卡片与 MACD 副图。

**Architecture:** 后端新增指标领域模型、MACD 计算器、指标仓储表和指标服务；全市场快照成功后刷新日线 MACD，列表接口通过指标表筛选与返回最近信号。前端扩展类型化 API、列表筛选器、股票表格列、详情页指标卡片，并让 K 线图可选展示 MACD 副图。

**Tech Stack:** Python 3.12、FastAPI 0.141.1、DuckDB 1.5.5、Pandas 3.0.5、React 19.2.8、TypeScript 7.0.2、ECharts 6.1.0、Vitest 4.1.10。

## Global Constraints

- 所有产品文案、日志中的描述性文本、README 和代码注释使用中文。
- 第一版只实现日线 MACD，不实现分钟级 MACD。
- 交易中使用当前最新价作为今日临时收盘价参与 MACD 计算，并显示为盘中信号。
- 列表页只新增“最近 MACD 信号”，不展示 DIFF、DEA、红绿柱数值。
- MACD 筛选条件只包含金叉/死叉、零轴上方/下方、今日/近 3 日/近 5 日。
- 今日、近 3 日、近 5 日都按交易日计算，不按自然日计算。
- 指标仅用于辅助分析，不构成投资建议。
- 普通自动化测试不得访问公网；在线烟雾测试必须显式启用。
- 每个任务遵守测试先行、最小实现、完整验证和独立提交。
