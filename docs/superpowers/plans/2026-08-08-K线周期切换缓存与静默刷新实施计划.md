# K 线周期切换缓存与静默刷新 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让详情页周期切换先展示本页缓存、后台静默刷新，并减少分钟级 MACD 的额外补数耗时。

**Architecture:** 前端在详情页组件内维护按周期分组的 K 线和 MACD 缓存；后端将分钟级 MACD 预补 K 线范围从 6 个月缩短到与页面默认一致的 60d。

**Tech Stack:** React、Vitest、FastAPI 服务层、pytest。

## Global Constraints

- 所有用户可见文案保持中文。
- 不改变现有接口路径和响应结构。
- 不引入新的外部依赖。
- 本次只优化详情页切换体验和分钟级 MACD 补数范围，不做全市场分钟级预计算。
