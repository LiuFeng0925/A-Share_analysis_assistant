# KDJ 副图坐标轴与交叉标签统一设计

## 目标

统一详情页副图的阅读方向和交叉信号表现：KDJ 纵轴刻度与 MACD 一样显示在左侧；KDJ 金叉、死叉竖线在顶部显示信号名称和日期。

## 展示规则

- KDJ 纵轴不再指定右侧位置，使用与 MACD 一致的左侧纵轴。
- KDJ 金叉、死叉继续使用现有红色、绿色虚线，并恢复顶部的“金叉/死叉 + 日期”标签。
- 20 超卖线、80 超买线保留虚线，但不显示文字标签。
- 超卖区、普通区、超买区保留背景色，但不显示区域文字。
- MACD、K 线及列表筛选行为不变。

## 实现边界

本次只调整前端 ECharts 配置，不修改 KDJ 指标计算、交叉判断、接口数据或静默刷新逻辑。KDJ 交叉标签直接复用 MACD 现有的垂直线标签生成逻辑，避免形成两套视觉规则。

## 验收标准

1. KDJ 纵轴配置位于左侧，J 值超出 0 到 100 时仍能完整扩展刻度范围。
2. KDJ 金叉和死叉竖线顶部显示信号名称和日期，颜色与 MACD 同方向信号一致。
3. 20/80 边界线与三区背景不显示文字。
4. 图表单元测试、前端构建和项目完整测试通过。
