# A 股雷达设计系统

## 产品与页面任务

- 产品：本地优先的中国 A 股行情研究工具。
- 用户：需要快速浏览全市场、搜索股票并进入 K 线详情的个人研究者。
- 列表页唯一任务：在高密度但不压迫的界面中定位一只股票。
- 详情页唯一任务：阅读可缩放的历史 K 线，并在“今日”视图查看一根代表一分钟的原生分钟 K。
- 页面结构：左侧只保留“全部股票”，不增加未实现菜单。

## 视觉方向

整体采用 HeroUI 式浅色、克制圆角与轻量分层。借鉴 Superdesign “Mosaic Grid Architecture Style”的技术网格、细分隔线和等宽数据标签，但不使用落地页大标题、森林绿主色、零圆角或装饰性拼贴。

设计风险集中在一个位置：股票涨跌单元格使用“价差标尺”——百分比旁带一条极短的红/绿刻度线，长度只表达涨跌方向与视觉强度，不替代真实数字。这让表格一眼具有行情工具身份，其余区域保持安静。

## 色彩令牌

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 雾蓝底 | `#F5F7FB` | 页面背景 |
| 纸白 | `#FFFFFF` | 卡片、表格、侧栏 |
| 墨色 | `#172033` | 标题与核心数字 |
| 灰蓝 | `#687386` | 次要文字、说明 |
| 品牌蓝 | `#3157D5` | 激活项、链接、焦点 |
| 边界蓝灰 | `#E4E9F2` | 分隔线、输入边框 |
| A 股红 | `#E5484D` | 上涨、阳线 |
| A 股绿 | `#16A36F` | 下跌、阴线 |

禁止紫色渐变、霓虹光、玻璃拟态、暖米色纸张背景与大面积红绿填充。

## 字体

- 标题与正文：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 价格、代码、时间与技术标签：`ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace`。
- 页面标题 24px/700；卡片主数字 22px/700；正文 14px/400；表头与元数据 12px/600。
- 数字统一 `font-variant-numeric: tabular-nums`，避免行情刷新时列宽跳动。

## 间距与布局

- 基础间距：4、8、12、16、20、24、32px。
- 左侧栏：桌面 208px；主内容最大宽度 1600px；页面内边距 24px。
- 卡片圆角 12px；输入与按钮圆角 10px；徽标圆角 6px。
- 卡片边框 1px `#E4E9F2`；仅使用 `0 6px 20px rgba(26, 43, 74, 0.06)` 的单层轻阴影。
- 表格单行高度约 56px，一只股票严格占一行。

## 结构线框

```text
┌──────── 208px ────────┬────────────────────────────────────┐
│ A 股雷达               │ 页面标题        市场状态 / 更新时间 │
│                        ├────────────────────────────────────┤
│ ● 全部股票             │ 概览卡 / 搜索 / 主表格或 K 线       │
│                        │                                    │
└────────────────────────┴────────────────────────────────────┘
```

小于 860px 时侧栏变为顶部紧凑栏，内容内边距降为 16px；表格允许水平滚动，不把一只股票拆成多张卡。

## 组件规则

- 导航激活项使用淡蓝背景、品牌蓝文字和 3px 左侧标记。
- 输入框有清晰标签或占位说明；焦点使用 2px 品牌蓝外环。
- 按钮动词明确；图标按钮必须有 `aria-label`。
- 列表刷新时保留旧数据；加载、空数据、接口失败与数据过期状态都提供下一步说明。
- A 股采用红涨绿跌；颜色必须同时配合正负号或文字，不能只靠颜色传义。
- K 线区以图表为主，不添加与分析无关的装饰。

## 动效与可访问性

- 只使用 120–180ms 的颜色、边框与轻位移动效。
- 不使用循环背景动画；行情变化可短暂淡入，不闪烁。
- `prefers-reduced-motion: reduce` 时关闭非必要过渡。
- 所有交互可键盘访问，焦点轮廓清晰，正文对比度不低于 WCAG AA。

## 自我审查

最初参考风格的森林绿、零圆角和大字号落地页结构不适合中文行情工具，已改为品牌蓝、克制圆角与数据密度优先。保留的只有细网格和等宽技术标签；独特性集中在“价差标尺”，不会把整个产品做成夸张金融终端。
